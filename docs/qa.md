## How this file gets populated

- During the talk: speaker captures questions on the back of the notes (verbal or written).
- Immediately after: open the room's Slack / Discord / chat channel and copy any DMs.
- Within 24h: triage. Anything that fits the existing `FAQ.md` shape — move it there. Anything that surfaces a real gap in the talk or article — file an issue in this repo, then update the canonical material.
- Within a week: close the loop with the asker if they left a handle.
